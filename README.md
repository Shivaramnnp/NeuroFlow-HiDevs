# NeuroFlow

NeuroFlow is an AI-powered Retrieval-Augmented Generation (RAG) platform designed to ingest, process, retrieve, and generate accurate responses from multiple data sources. The system supports document ingestion, hybrid retrieval, intelligent model routing, automated evaluation, and fine-tuning workflows.

This repository contains the architecture, API contracts, data models, and design decisions for the NeuroFlow project.
